# Moe Utils
Mapart related utilities for Minecraft (as a Meteor Client Addon).  
Printer recently updated with movement logic!

### Supported versions
- 26.2
- 1.21.4

Get automatic builds [here](https://github.com/Kyuunex/moe-utils/releases)

### Modules
+ Mapart printer (forked from Vali's), now includes movement logic.
+ Map area highlighter
+ LoadEntireSchematics - (instead of just render distance sections)

### Commands
+ `quicksave-map` quickly saves a map you are holding, locally.

### Note
This printer is maintained with 9b9t in mind. 
Constantiam may work but that server doesn't allow touching inventory while moving.

### Required mods
+ Litematica
+ Baritone
+ Meteor Client
